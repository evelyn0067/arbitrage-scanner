# ⚡ ArbiScan — CEX/DEX 套利扫描器

实时扫描 **Hyperliquid、AsterDEX、Binance、OKX、Bybit、Gate** 之间的套利机会，通过各交易所 WebSocket 实时推送行情，支持一键双边下单。纯前端（HTML + CSS + 原生 JS），无需构建、无依赖。

## 快速启动

```bash
# 推荐：本地 HTTP 服务（避免 CORS 问题）
python3 -m http.server 8080
# 然后访问 http://localhost:8080

# 或直接浏览器打开
open index.html
```

## 功能

### 套利类型
| 类型 | 说明 |
|------|------|
| 资金费率套利 | 在资金费高的交易所做空、低的做多，赚取费率差 |
| 价差套利 | 同一资产在不同交易所价差超过手续费时搬砖 |
| 期现套利 | 现货 + 永续空单，收取资金费 |

### 实时数据层（WebSocket 为主 + REST 兜底）
- **WebSocket 实时推送**：OKX / Gate / Bybit / AsterDEX 走 WS 秒级更新，彻底绕开 OKX 的 REST 限速。
- **自动兜底**：任一交易所 WS 断线或数据超时，自动回退到 REST 轮询；连上后再切回。
- **Binance 容错**：部分网络会静默丢弃 Binance WS 数据——检测不到数据即自动用 REST（已验证可用）。
- **Hyperliquid**：单次 REST 即可拿全量，采用快轮询。
- `state.markets` 为唯一数据源，2s 节流重绘，抽屉打开时暂停重排以免打断操作。

### 资金费率口径（统一归一化到 8h）
所有交易所的费率都归一化为 **8h 口径**再参与年化排序：`fr8h = 每周期费率 × (8 / 周期小时数)`。已处理各所可变结算周期（Bybit `fundingIntervalHour`、Gate/OKX 动态周期），避免费率被错误放大/缩小而污染排名。

### 「近 7 天净盈亏」综合回测
点开任一机会的详情抽屉，给出 **综合口径** 的历史回测：

```
净盈亏 = 资金费毛收入 ＋ 价差/基差盈亏 − 手续费 − 滑点
```
- **资金费**：两条腿各交易所的真实历史结算（funding history 接口），按 8h 桶对齐，净 = 空头腿费率 − 多头腿费率。
- **价差/基差盈亏**：假设「7 天前开仓 → 现在平仓」，净 = 多头腿收益率 − 空头腿收益率。
- **手续费**：双腿 taker × 开 + 平。
- **滑点**：按当前 ±0.5% 挂单深度估算（本金超过单侧深度会标注「深度不足」）。
- 同时给出结算胜率、负费率亏损分析（偶发/阶段性/持续性）与综合评分。
- ⚠️ 价差与滑点为估算（历史标记价 + 当前深度快照），非真实成交；未计杠杆借贷成本。

### 界面主题（🎨 右上角切换）
内置多套可切换主题，选择记忆在本地：
- **简约**：极简白、暖纸、午夜蓝
- **有趣**：波普涂鸦（粗描边硬投影）、糖果马卡龙（大圆角）、蒸汽波（霓虹渐变）、像素机厅（CRT 扫描线）

### 下单功能
- 配置各交易所 API Key（仅存浏览器 localStorage，不上传任何服务器）
- 单边 / 双边一键下单，限价 / 市价，杠杆 1x/3x/5x/10x
- 实时 P&L 预估

## 注意事项

1. **CORS 限制**：部分 CEX REST（如 Binance）禁止前端直连；WS 跨域一般放行，故实时层优先走 WS。
2. **Hyperliquid 下单**：需 EVM 钱包签名，前端直连暂不支持，建议在 HL 官网手动下单。
3. **API Key 安全**：只开「交易」权限，务必禁用「提款」权限。
4. **套利风险**：资金费率可能反向，建议设退出阈值；单边暴露时及时平仓。

## 技术说明
- 纯前端，无构建步骤；`index.html` + `app.js` + `style.css`。
- CSS 完全 token 化，主题通过 `html[data-theme=...]` 覆盖 token 实现。
- 代码不含任何密钥，API Key 由用户运行时在本地填写。
